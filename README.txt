ASTERIA — EXOPLANET HABITABILITY ANALYZER

Files:
1. index.html — complete functional single-file web application.
2. README.txt — project information.

Run:
Open index.html directly in any modern browser.

Demo:
Enter:
Temperature: 22.5 °C
Distance: 1.00 AU
Mass: 1.00 M⊕

Then click SCAN PLANET.

The application performs a client-side simulated habitability calculation using:
- Temperature: 40% weight
- Orbital distance: 30% weight
- Planetary mass: 30% weight

This is a hackathon demonstration model, not a scientific or engineering colonization assessment.

Keyboard shortcut:
Press D outside an input field to populate Earth-like demonstration values.
